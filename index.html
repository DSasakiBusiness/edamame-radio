YouTube上で24時間稼働しているAI音楽ラジオです。視聴者がライブチャットで曲をリクエストすると、AIがその場でオリジナル楽曲を生成して配信で再生します。MCのキャラクターが視聴者と会話し、話した内容を記憶して次回以降の応答に反映します。

このアプリケーションについて

本アプリケーションは配信運営者本人が自身のYouTubeチャンネルを運営するために使用する非公開のツールです。一般利用者向けに配布・提供されるサービスではありません。

YouTube APIの利用範囲

  • 自チャンネルのライブチャットメッセージの取得（liveChatMessages.list）
  • 自チャンネルのライブ配信の作成・更新・終了（liveBroadcasts）

検索（search.list）、他者チャンネルのデータ収集、動画のダウンロードは一切行いません。

取得する情報

本アプリケーションは、配信中のYouTubeライブチャットに投稿されたメッセージについて、以下の情報を取得します。

  • チャットメッセージの本文
  • 投稿者の表示名およびYouTubeチャンネルID
  • 投稿日時

これらはYouTubeのライブチャット上で公開されている情報です。メールアドレス、パスワード、支払い情報などの非公開情報は取得しません。

利用目的

  • 配信中にMCキャラクターが視聴者へ返答するため
  • 楽曲リクエストを受け付け、生成する楽曲の内容に反映するため
  • 視聴者が再訪した際に、過去の会話を踏まえた応答をするため

保存と管理

取得した情報は配信運営者が管理するローカル環境にのみ保存されます。第三者への提供、販売、外部サービスへの転送は行いません。広告目的での利用も行いません。

記憶として保存される内容は、視聴者が実際に投稿した文言を根拠として保持します。発言していない内容を推測して保存することはありません。

削除の請求

ご自身に関する保存内容の削除を希望される場合、ライブチャットで !forget と投稿してください。該当する記憶は削除されます。個別のご連絡をご希望の場合は下記の連絡先までお知らせください。

Googleユーザーデータの取り扱い

本アプリケーションによるGoogleユーザーデータの使用および他アプリへの移転は、限定使用要件を含むGoogle API サービスのユーザーデータに関するポリシーに準拠します。
